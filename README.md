# My HomeLab
This serves as a way to show what I have and planed as a set up for a Homelab, to show my interests and understanding without openly doxxing myself.

## I currently have:
- A jellyfin server to host my owned music and movies.
- Tailscale to connect to my host machine and access my Jellyfin server.
- A domain using CloudlFlare to keep my personal IP adress more secure.

## I plan on setting up:
- A second reverse proxy for my network's open ports to block requests that aren't coming from Cloudflare.
- Two simple self hosted website's to show off, personal projects and a professional portfolio.
- Proxmox to use containers and virtaulisation to host and run any servers/services I want.
